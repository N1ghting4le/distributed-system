# Fleet Simulator

Эмулятор бортового оборудования парка: N машин движутся по трассам маршрутов, отправляют координаты каждые 10 с, валидации на остановках и инциденты с заданной вероятностью. Параметры – число машин, интенсивность, общее число сообщений, доля ошибочных данных. Реализуется в ЛР 2, используется как генератор нагрузки в ЛР 6.
