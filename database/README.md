# Хранилище (PostgreSQL)

- `init/001_schema.sql` – схема `transit`: справочники, трек (секционирование по суткам), состояние парка, прибытия, пассажиропоток, инциденты, служебные таблицы идемпотентности. Скрипты из `init/` выполняются контейнером PostgreSQL при первом запуске (ЛР 4).
- `init/003_reliability.sql` – ЛР 3: номер попытки в `processed_messages`, журнал попыток `processing_log`; применяется и к уже развернутой БД.
- `tests/smoke_test.sql` – проверка схемы на примерах сообщений из `docs/examples`.
